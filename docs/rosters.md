## 6. Naming register — locked (§12 #10)

- **Units** → street handles (gritty, Gibson/Stephenson): *Last-Mile, Null, Hollowpoint, Sawbones, Dispatch.*
- **Corps** → corporate originals + a tagline that hints the mechanic.
- **Clans** → evocative gang/clan names (*Steel Lotus, The Maws*).
- **Law** → institutional names (*Metro PD, The Bureau*).
- **Abilities / gear** → plain-tech or street slang (*Redline, Dust-off, Dead-zone, Field-strip*).
- **IP air-gapped:** all original; trademarked terms (Trauma Team, Netrunner-as-class) avoided; the mechanic carries the homage, never the name.
